# Modular Python Data Processing Pipeline

A robust, production-ready ETL data processing pipeline built with Python and Pandas.

## Features
- **Multi-source Extraction**: Read data from CSV, JSON, or external REST APIs.
- **Robust Transformation**: Handles missing values with configurable strategies (mean/median/custom fill), removes duplicates, and safely parses dates.
- **Configuration Driven**: Centralized YAML configuration for easy parameter adjustments.
- **Structured Logging**: Comprehensive error tracking and audit logs to console and log files.
